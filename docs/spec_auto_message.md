# 자동 메시지 스펙

## 1. 개요

| 항목 | 값 |
| --- | --- |
| 문서명 | spec_auto_message |
| 작성일 / 최종 수정일 | 2026-11-14 / 2026-11-15 |
| 버전 | 1.0 |
| 기준 커밋 ID | f6d2cde |

- **기능명:** 일정 간격 자동 메시지 (UC3)
- **목적 (Why):** 길드·파티 모집 공지처럼 같은 메시지를 반복해 보내는 일을 손으로 하지 않게 한다.

## 2. 목표 및 범위

### In Scope

- 자동 메시지 항목(채널·간격·메시지·대상·켜짐)의 추가·편집·삭제·켜기/끄기와 반복 전송

### Out of Scope

- 보낼 시간대·횟수 제한, 채널 자동 입장
- 거래 같은 공개 채널로 보내기 → WoW 가 사용자 입력 없이 보낸 메시지를 막는다 (D#10)

## 3. 요구사항

### 3.1 사용자 스토리

- `US#3` [as-built] 길드·파티에 같은 공지를 반복해 알리는 플레이어로서, 같은 메시지를 반복해 치지 않기 위해, 정해 둔 메시지가 일정 간격으로 자동 전송되기를 원한다 → FR#14~FR#18

### 3.2 기능 요구사항

- `FR#14` [as-built] 전송은 항목이 켜져 있고 메시지가 비어 있지 않을 때, 채널 조건이 맞을 때만 한다. 맞지 않으면 아무것도 하지 않는다.

  | 채널 | 조건 | 보내는 곳 |
  | --- | --- | --- |
  | 길드 | 길드 소속 | 길드 |
  | 파티 | 그룹 중 | 파티 |
  | 공격대 | 공격대 중 | 공격대 |
  | 귓속말 | 대상 이름이 비어 있지 않음 | 대상 |

  - 표에 없는 채널(이전 버전에서 저장한 거래 `TRADE` 포함)은 보내지 않는다 (D#10).
- `FR#15` [as-built] 켜진 항목 중 FR#14 표의 채널인 항목마다 반복 타이머를 둔다. 간격은 초 단위이고, 숫자가 아니면 60, 1 미만이면 1 이다. 로드할 때 켜진 항목을 모두 시작한다(색인 NFR#5). 한 항목을 다시 시작하면 이전 타이머를 끈다.
- `FR#16` [as-built] 설정 창의 자동 메시지 패널

  ```
  When   자동 메시지 패널을 연다
  Then   항목마다 한 줄: 채널(귓속말은 대상이 있으면 ": 대상" 붙임), 간격(로케일 형식: enUS "{n}s", koKR "{n}초"), 메시지(줄바꿈은 공백으로 한 줄), [켜기/끄기]·[편집]·[삭제]
         꺼진 항목과 FR#14 표에 없는 채널의 항목은 회색, 항목이 없으면 안내
  When   [켜기/끄기]·[삭제] 또는 대화상자 저장
  Then   DB 를 바꾸고 모든 자동 메시지 타이머를 다시 시작하고 목록을 다시 그린다
  ```

- `FR#17` [as-built] 편집 대화상자: 패널의 [추가]·[편집] 또는 `/tl add` 로 연다.
  - 채널 드롭다운: 귓속말·파티·공격대·길드 (기본 귓속말). 귓속말이면 대상 입력란이 보인다.
  - FR#14 표에 없는 채널의 항목을 편집하면 기본 채널로 보여 준다 → 저장하면 그 채널로 바뀐다.
  - 간격 슬라이더 10~600초, 5초 단위, 기본 60. 편집 시 저장된 값을 이 범위로 맞춰 보여 준다.
  - 여러 줄 메시지 입력. 입력란에 초점이 있을 때 아이템을 Shift+클릭하면 링크를 넣는다.
  - [확인]: 간격을 5초 단위로 반올림(최소 10)해 저장 → 새 항목은 목록 끝에 켜진 상태로 추가, 편집은 그 자리를 바꾸고 켜짐·꺼짐은 편집 전 값을 그대로 둔다. [취소]: 저장하지 않고 닫는다.
- `FR#18` 로드할 때 FR#14 표에 없는 채널의 항목이 하나라도 있으면 대화창에 한 번 안내한다 (색인 NFR#5). 켜짐·꺼짐과 무관하다.

  | 로케일 | 안내 |
  | --- | --- |
  | enUS | `Auto messages to the Trade channel are blocked by WoW and are not sent. Edit them to another channel or delete them.` |
  | koKR | `거래 채널 자동 메시지는 WoW 가 막아 보내지 않습니다. 다른 채널로 편집하거나 삭제하세요.` |

## 4. 데이터 및 API 스펙

- `TradeLedgerDB.autoMessages`: 순서 있는 목록. 항목 `{ channel = "GUILD"|"PARTY"|"RAID"|"WHISPER", interval = number, message = string, enabled = boolean, target = string }`
  - 이전 버전에서 저장한 `"TRADE"` 항목은 지우지 않고 남긴다 → 사용자가 메시지를 다른 채널로 옮길 수 있다.
- `ns.AUTO_MSG_CHANNELS`: 보낼 수 있는 채널 키의 순서 있는 목록. 대화상자 드롭다운 순서이고 첫 값이 기본 채널이다.
- `ns:IsAutoMessageChannel(channel)`, `ns:AutoMessageDialogChannel(entry)`(편집 대화상자가 보여 줄 채널), `ns:NotifyUnsendableAutoMessages()`
- `ns:AutoMessageDialogInterval(entry)`: 편집 대화상자가 보여 줄 간격 (없으면 60, 10~600 으로 맞춤)
- `ns:AutoMessageRow(entry)`: 패널 한 줄 `{ channel, interval, message, toggle, dimmed }` (FR#16)
- `ns:SendAutoMessage(entry)`, `ns:StartAutoMessage(i)`, `ns:StopAutoMessage(i)`, `ns:StartAllAutoMessages()`, `ns:StopAllAutoMessages()`, `ns:RestartAllAutoMessages()`
  - 실행 중 타이머: `ns.autoMessageTimers[i]` (목록 순번 기준)
