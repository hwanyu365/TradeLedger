# 자동 메시지 스펙

## 1. 개요

| 항목 | 값 |
| --- | --- |
| 문서명 | spec_auto_message |
| 작성일 / 최종 수정일 | 2026-11-14 / 2026-11-14 |
| 버전 | 1.0 |
| 기준 커밋 ID | d0dd1ce |

- **기능명:** 일정 간격 자동 메시지 (UC3)
- **목적 (Why):** 거래 채널 홍보처럼 같은 메시지를 반복해 보내는 일을 손으로 하지 않게 한다.

## 2. 목표 및 범위

### In Scope

- 자동 메시지 항목(채널·간격·메시지·대상·켜짐)의 추가·편집·삭제·켜기/끄기와 반복 전송

### Out of Scope

- 보낼 시간대·횟수 제한, 채널 자동 입장

## 3. 요구사항

### 3.1 사용자 스토리

- `US#3` [as-built] 거래 채널에서 물건을 파는 플레이어로서, 같은 홍보를 반복해 치지 않기 위해, 정해 둔 메시지가 일정 간격으로 자동 전송되기를 원한다 → FR#14~FR#17

### 3.2 기능 요구사항

- `FR#14` [as-built] 전송은 항목이 켜져 있고 메시지가 비어 있지 않을 때, 채널 조건이 맞을 때만 한다. 맞지 않으면 아무것도 하지 않는다.

  | 채널 | 조건 | 보내는 곳 |
  | --- | --- | --- |
  | 거래 | 이름 `Trade` 인 채널 번호가 0 보다 큼 | 그 번호의 채널. 전송 오류는 무시 |
  | 길드 | 길드 소속 | 길드 |
  | 파티 | 그룹 중 | 파티 |
  | 공격대 | 공격대 중 | 공격대 |
  | 귓속말 | 대상 이름이 비어 있지 않음 | 대상 |

  - koKR 클라이언트에서 거래 채널을 찾는지는 #23 에서 확인한다.
- `FR#15` [as-built] 켜진 항목마다 반복 타이머를 둔다. 간격은 초 단위이고, 숫자가 아니면 60, 1 미만이면 1 이다. 로드할 때 켜진 항목을 모두 시작한다(색인 NFR#5). 한 항목을 다시 시작하면 이전 타이머를 끈다.
- `FR#16` [as-built] 설정 창의 자동 메시지 패널

  ```
  When   자동 메시지 패널을 연다
  Then   항목마다 한 줄: 채널(귓속말은 대상이 있으면 ": 대상" 붙임), 간격(로케일 형식: enUS "{n}s", koKR "{n}초"), 메시지(줄바꿈은 공백으로 한 줄), [켜기/끄기]·[편집]·[삭제]
         꺼진 항목은 회색, 항목이 없으면 안내
  When   [켜기/끄기]·[삭제] 또는 대화상자 저장
  Then   DB 를 바꾸고 모든 자동 메시지 타이머를 다시 시작하고 목록을 다시 그린다
  ```

- `FR#17` [as-built] 편집 대화상자: 패널의 [추가]·[편집] 또는 `/tl add` 로 연다.
  - 채널 드롭다운(기본 거래), 귓속말을 고르면 대상 입력란이 보인다.
  - 간격 슬라이더 10~600초, 5초 단위, 기본 60. 편집 시 저장된 값을 이 범위로 맞춰 보여 준다.
  - 여러 줄 메시지 입력. 입력란에 초점이 있을 때 아이템을 Shift+클릭하면 링크를 넣는다.
  - [확인]: 간격을 5초 단위로 반올림(최소 10)해 저장 → 새 항목은 목록 끝에 켜진 상태로 추가, 편집은 그 자리를 바꾸며 켜진 상태가 된다 (#21). [취소]: 저장하지 않고 닫는다.

## 4. 데이터 및 API 스펙

- `TradeLedgerDB.autoMessages`: 순서 있는 목록. 항목 `{ channel = "TRADE"|"GUILD"|"PARTY"|"RAID"|"WHISPER", interval = number, message = string, enabled = boolean, target = string }`
- `ns:SendAutoMessage(entry)`, `ns:StartAutoMessage(i)`, `ns:StopAutoMessage(i)`, `ns:StartAllAutoMessages()`, `ns:StopAllAutoMessages()`, `ns:RestartAllAutoMessages()`
  - 실행 중 타이머: `ns.autoMessageTimers[i]` (목록 순번 기준)
