# 거래 장부 스펙

## 1. 개요

| 항목 | 값 |
| --- | --- |
| 문서명 | spec_trade_history |
| 작성일 / 최종 수정일 | 2026-11-14 / 2026-11-14 |
| 버전 | 1.0 |
| 기준 커밋 ID | d0dd1ce |

- **기능명:** 거래 장부 저장·정리·삭제·조회 (UC2)
- **목적 (Why):** 채팅 알림은 지나가면 사라진다 → 최근 거래를 게임 안에서 다시 확인할 수 있게 남긴다.

## 2. 목표 및 범위

### In Scope

- 완료·취소 거래의 장부 저장, 보관 개수·기간 제한, 전체 삭제, 설정 창의 장부 패널

### Out of Scope

- 보관 개수를 화면에서 바꾸는 설정 → DB 값(`history.maxEntries`)만 있다
- 장부 검색·필터·내보내기 (색인 제외 범위)

## 3. 요구사항

### 3.1 사용자 스토리

- `US#2` [as-built] 거래를 자주 하는 플레이어로서, 지난 거래 내용을 다시 확인하기 위해, 최근 거래가 게임 안에 기록되기를 원한다 → FR#9~FR#13

### 3.2 기능 요구사항

- `FR#9` [as-built] 거래가 완료·취소로 처리되면(`spec_trade_alert.md` FR#3·FR#4) 장부에 한 건을 추가한다. 장부가 꺼져 있으면 추가하지 않는다.
  - 항목: 시각, 상대, 양쪽 아이템(슬롯 1~7 의 이름·수량, 링크는 저장하지 않음), 양쪽 골드(없으면 0), 성공 여부
- `FR#10` [as-built] 장부가 최대 개수(기본 50)를 넘으면 가장 오래된 항목부터 지운다.
- `FR#11` [as-built] 로드할 때 7일(604800초)보다 오래된 항목을 지운다. 정확히 7일 된 항목은 남긴다. 게임 중에는 정리하지 않는다.
- `FR#12` [as-built] 장부 패널의 삭제 버튼(enUS `Clear`, koKR `초기화`) → 확인 대화상자 → 확인 시 장부를 비우고, 삭제 안내를 대화창에 출력하고, 장부 패널을 갱신한다.
- `FR#13` [as-built] 설정 창의 장부 패널

  ```
  Given  장부에 항목이 있다
  When   장부 패널을 연다
  Then   최신 항목이 위로 오는 목록: 시각(월/일 시:분), 결과(성공 초록·취소 빨강), 상대, 보낸 것·받은 것 한 줄 요약
  When   목록의 한 줄을 누른다
  Then   그 줄이 강조되고 아래 상세에 전체 시각(연-월-일 시:분:초)·결과·상대·보낸 것·받은 것(줄바꿈 허용)이 보인다
  Given  장부가 비어 있다
  Then   기록 없음 안내, 상세에는 선택 안내
  ```

  - 패널 위쪽 체크박스로 장부 켜기·끄기, 요약의 아이템 목록은 수량 2 이상이면 ` x{수량}`, 골드는 끝에 금액, 비면 `-`

## 4. 데이터 및 API 스펙

- `TradeLedgerDB.history`: `{ enabled = true, maxEntries = 50, entries = { ... } }` (오래된 것부터 순서대로)
- 항목: `{ time = <time()>, partner = string, myItems = {[slot] = {name, quantity}}, theirItems = {...}, myGold = number, theirGold = number, success = boolean }`
- `ns:SaveTrade(partner, myItems, theirItems, myGold, theirGold, success)`, `ns:PruneHistory()`, `ns:ClearHistory()`
